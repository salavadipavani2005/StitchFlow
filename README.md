# 🧵 StitchFlow

## Tailoring Shop Management System

StitchFlow is a web-based tailoring shop management system designed to help manage the daily operations of a textile and tailoring business.

The project was inspired by a real-world tailoring shop and helps manage customers, garment measurements, orders, delivery dates, and payment details.

---

## ✨ Features

### 👥 Customer Management

* Add new customers
* Edit customer details
* Delete customers
* Search customers by name or phone number
* View complete customer details

### 📏 Measurement Management

* Store customer measurements
* Support measurements for different garment types
* Edit measurements
* Delete measurements

### 👔👗 Multiple Garment Types

The system supports garments for both men and women, including:

* Shirt
* Pant
* Kurta
* Blouse
* Kurti
* Dress
* Other garments

### 📦 Order Management

* Create new orders
* Select customers for orders
* Add garment details and quantity
* Track total amount
* Record advance payment
* Automatically calculate remaining payment
* Set delivery dates

### 🔄 Order Status Tracking

Orders can be updated through different stages:

* Received
* Cutting
* Stitching
* Ready
* Delivered

### 📅 Due Soon Tracking

The dashboard automatically displays orders that need to be delivered within the next few days.

It also identifies:

* 🔥 Due Today
* 📅 Due Tomorrow
* ⏳ Due in upcoming days

### 👁️ Customer Details

View a customer's:

* Personal information
* Saved measurements
* Previous orders
* Pending payments
* Upcoming deliveries

### 💾 Data Storage

All customer, measurement, and order data is stored using the browser's **LocalStorage**.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional software or installation is required.

---

## 💡 Project Purpose

StitchFlow was created to provide a simple digital solution for managing a tailoring and textile shop.

The system helps reduce manual record keeping and makes it easier to track customers, measurements, orders, payments, and delivery deadlines.
